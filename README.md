# NovaKit Bookmarklets

**Zero-install, one-click web superpowers.**  
Copy the `javascript:(...)` line from any file in `bookmarklets/`, paste it into a bookmark’s URL, and click it on any page.

> Works in Chrome, Edge, Brave, Firefox. On iOS Safari, bookmarklets work but setup is clunky; keep code short.

## What is this?
A curated set of tiny, auditable bookmarklets that do one thing well: extract links, outline headings, clean URLs, kill sticky overlays, export tables, gather DOIs/emails, and more. Ideal for research, OSINT, and getting unstuck on hostile web UIs.

## Quick Start
1. Create a new bookmark.
2. Name it (e.g., “Outline Headings”).
3. Paste the entire line starting with `javascript:` into the URL field.
4. Open any page → click the bookmark.

If clipboard is blocked, most spells open a `data:` tab as a safe fallback.

## Highlights
- **Research:** outline headings, external links, quick citations
- **Data:** tables → CSV, JSON blob extractor
- **Scholar:** highlight → Scholar/Semantic/LibGen; DOIs → Sci-Hub mirrors
- **Cleanup:** strip tracking params, kill sticky overlays, instant dark mode
- **OSINT:** emails/phones/DOIs finder; robots/sitemap/.well-known openera

See `bookmarklets/` for the full list.
